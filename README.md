# А-ключница — менеджер паролей для Windows, iPhone и Android

Одно приложение для всех трёх платформ. Оно устанавливается из браузера как обычное приложение (с иконкой на рабочем столе или главном экране) и работает без интернета.

## Что умеет

- **Группы.** Сразу есть «Работа» и «Дом», можно добавить свои: «Семья», «Финансы», «Покупки» и любые другие. У каждой группы свой значок и цвет. Записи переносятся между группами по одной или сразу пачкой (кнопка «Выбрать» или долгое нажатие на запись).
- **Записи:** название, логин, пароль, сайт, заметки, избранное. Одно нажатие копирует логин или пароль, а буфер обмена потом сам очищается.
- **Генератор паролей** с настройкой длины и набора символов. Подсказывает, если пароль слабый или уже используется в другой записи.
- **Поиск** сразу по всем группам.
- **Синхронизация и перенос** между устройствами через зашифрованный файл или текст. Можно перенести всё хранилище или только одну группу.
- **Автосинхронизация на компьютере** через папку OneDrive, Google Диска или Яндекс Диска.
- **Импорт** из Chrome, Edge, Firefox, Bitwarden, KeePass и других через CSV.
- **Автоблокировка** при бездействии (от 1 до 60 минут).

## Как защищены данные

- Всё шифруется прямо на устройстве: **AES-256-GCM**. Ключ вычисляется из мастер-пароля (**PBKDF2-SHA-256, 600 000 итераций**), поэтому подбор пароля к украденному файлу очень медленный.
- Мастер-пароль нигде не сохраняется. Ключ живёт только в памяти, пока хранилище открыто, и стирается при блокировке.
- Приложение **ничего не отправляет в интернет**: нет серверов, аккаунтов, аналитики и рекламы. Это дополнительно закреплено политикой безопасности страницы (CSP): браузер просто не даст коду обратиться к сети.
- Файлы синхронизации зашифрованы так же. Без пароля это бессмысленный набор символов.

> ⚠️ **Мастер-пароль нельзя восстановить.** Если его забыть, расшифровать пароли не сможет никто. Придумайте фразу из 4–5 слов, которую точно запомните (например, «синий-трамвай-ест-облака»), и держите копию хранилища на втором устройстве.

## Установка

Приложению нужен адрес в интернете с HTTPS. Сами пароли туда **не попадают**: там лежит только код приложения, а данные хранятся на ваших устройствах. Проще всего бесплатно разместить его на GitHub Pages (5 минут, один раз).

### Шаг 1. Размещение на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Нажмите **«+» → New repository**. Имя, например, `a-klyuchnitsa`, тип **Public** → **Create repository**.
3. На странице репозитория нажмите **«uploading an existing file»** и перетащите **всё содержимое** этой папки (`index.html`, `sw.js`, `manifest.webmanifest`, папку `icons`, этот README) → **Commit changes**.
4. Откройте **Settings → Pages**. В «Source» выберите **Deploy from a branch**, ветка **main**, папка **/(root)** → **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/a-klyuchnitsa/`.

Подойдёт и любой другой хостинг статических сайтов с HTTPS (Netlify, Cloudflare Pages и т. п.).

### Шаг 2. Установка на устройства

**iPhone / iPad**
1. Откройте адрес в **Safari**.
2. Нажмите **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **«Добавить»**.
3. Запускайте А-ключницу с иконки: так она работает как отдельное приложение и надёжнее хранит данные.

**Android**
1. Откройте адрес в **Chrome**.
2. Меню **⋮** → **«Установить приложение»** (или **«Добавить на главный экран»**).

**Windows**
1. Откройте адрес в **Edge** или **Chrome**.
2. Нажмите значок установки справа в адресной строке (или меню **⋯ → Приложения → Установить**).
3. А-ключница появится в меню «Пуск» и на рабочем столе.

> На Windows можно обойтись и без хостинга: просто откройте `index.html` двойным щелчком в Edge или Chrome. Всё будет работать, но значка приложения не будет.

## Первый запуск

- **На первом устройстве** придумайте мастер-пароль → «Создать хранилище».
- **На остальных устройствах** нажмите **«Перенести с другого устройства»**. На первом устройстве откройте **Синхронизация** → «Сохранить файл», «Поделиться» или «Скопировать как текст», а на новом выберите этот файл (или вставьте текст) и введите пароль. Мастер-пароль на новом устройстве станет таким же. Так удобнее: файлы с любого вашего устройства будут открываться без лишних вопросов.

## Синхронизация и перенос

Кнопка **⟳ Синхронизация** в верхней панели. Два действия:

- **«Отправить на другое устройство»** — создаёт зашифрованный файл (или текст).
- **«Получить с другого устройства»** — открывает такой файл и **сливает** его с вашими данными: новые записи добавляются, изменённые обновляются, удалённые удаляются. Если одну запись меняли на двух устройствах, остаётся более свежая версия. Повторно открыть тот же файл безопасно: дублей не будет.

### Типичные сценарии

**Компьютер (автоматически).** Синхронизация → **«Создать файл синхронизации»** → сохраните его в папку OneDrive, Google Диска или Яндекс Диска. Дальше А-ключница сама записывает туда изменения и подхватывает чужие. Работает в Edge и Chrome. Если браузер после перезапуска спросит разрешение на доступ к файлу, на кнопке синхронизации появится точка: нажмите «Синхронизировать».

**Телефон ↔ компьютер через облако.** На телефоне: Синхронизация → **«Открыть файл…»** → выберите файл синхронизации в iCloud Drive / Google Диске / Яндекс Диске. Изменения с телефона отправляйте обратно через **«Поделиться…» → сохранить в ту же облачную папку**, а на компьютере откройте его через «Открыть файл…».

**Через Telegram или любой мессенджер.** **«Скопировать как текст»** → вставьте в «Избранное» → на другом устройстве скопируйте и нажмите **«Вставить текст»**. Текст зашифрован.

**Только рабочие пароли на рабочий ноутбук.** В поле «Что передать» выберите **«Только группа 💼 Работа»**. Домашние пароли на работу не попадут.

**Передать группу другому человеку.** Выберите группу и **«Отдельным паролем»**. Сообщите этот пароль получателю отдельно, не в том же сообщении, что и файл. Ваш мастер-пароль он не узнает.

## Резервные копии

Браузер может очистить данные сайта (особенно на iPhone, если приложение долго не открывать), а телефон может потеряться. Поэтому:
- держите А-ключницу хотя бы на двух устройствах **или**
- раз в пару недель сохраняйте файл через «Синхронизацию» в облако. А-ключница сама напомнит, если копии давно не было.

## Импорт паролей из браузера

Настройки → **«Импорт из CSV»**. Сначала выгрузите пароли из браузера: Chrome/Edge — «Менеджер паролей → Экспорт паролей», Firefox — «Пароли → ⋯ → Экспорт». Папки из Bitwarden/KeePass превращаются в группы. **После импорта удалите CSV-файл**: в нём пароли лежат открытым текстом.

## Если забыли мастер-пароль

Восстановить его нельзя. Если А-ключница есть на другом устройстве, где вы помните пароль, или есть файл копии: на экране входа нажмите «Забыли мастер-пароль?» → сотрите хранилище на этом устройстве → «Перенести с другого устройства».

## Обновление приложения

Замените файлы в репозитории новыми. Если меняли код, увеличьте номер в первой строке `sw.js` (`kluchnitsa-v1` → `kluchnitsa-v2`), иначе устройства продолжат показывать сохранённую старую версию. Данные при обновлении не теряются.

## Честно об ограничениях

- Это самостоятельная разработка, и она **не проходила независимый аудит безопасности**. Шифрование построено на стандартных встроенных средствах браузера (Web Crypto), а не на самописных алгоритмах. Если нужна проверенная годами защита, посмотрите на открытые и проверенные аудитами Bitwarden или KeePassXC.
- А-ключница **не подставляет пароли автоматически** в другие приложения и сайты (веб-приложениям это недоступно): нужно копировать и вставлять.
- На телефонах синхронизация **ручная**: веб-приложение не может само читать облачные папки в фоне. На компьютере синхронизация автоматическая.
- Конфликты решаются по времени изменения, поэтому на устройствах должны быть правильные дата и время.
- Безопасность приложения зависит и от места, где оно размещено: держите его в **своём** аккаунте GitHub.

## Технические детали

- Формат файла `.kluch` — JSON: `{app, v, kdf, iter, salt, iv, ct}`. `ct` — AES-256-GCM, ключ из PBKDF2-SHA-256 с `iter` итерациями и случайной солью, параметры KDF защищены как связанные данные (AAD). Текстовый перенос — тот же JSON в Base64 с префиксом `KLUCH1:`.
- Удаления передаются «надгробиями» (`tomb: {id: время}`), поэтому удалённая запись не воскресает при слиянии.
- Хранилище на устройстве лежит в `localStorage` браузера только в зашифрованном виде. Приложение просит у браузера постоянное хранилище (`navigator.storage.persist`).
- Автосинхронизация на компьютере использует File System Access API (Chrome, Edge).
- Весь код — один файл `index.html`, без внешних библиотек.
